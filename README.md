# 自动修复信号 (fix_signal_auto)

一个 Magisk 模块：开机后自动开关一次飞行模式，修复Blue Fox Aura A1手机root后联通手机重启后 SIM 解锁但无信号的问题。支持 WebUI 配置页。

## 适用场景

- 运营商已退网 2G/3G（如中国联通），手机重启后 SIM 解锁完成但显示无信号
- 需要手动开关飞行模式才能恢复信号的设备（常见于国际版/小众品牌机型）

## 功能

- 三种触发方式（可配置）：
  - SIM 卡解锁后
  - SIM 卡无信号时（常驻监控，自动重试）
  - 开机后首次解锁（输锁屏密码）
- 可配置等待时间、飞行模式持续时间、无信号重试间隔
- WebUI 配置页（无需手动编辑文件）

## 工作原理

```
触发条件满足 → 等待 N 秒 → 开关一次飞行模式(持续 M 秒)
```

「无信号」模式为常驻监控：检测到无信号时开关飞行模式，未恢复则按间隔重试；用户主动开启飞行模式时不干预。

## 配置页

打开 **Magisk → 模块 → 自动修复信号 → 「操作」(Action) 按钮**，浏览器会打开 WebUI 配置页。

| 配置项 | 形式 | 范围 |
|--------|------|------|
| 触发动作 | 单选 | SIM卡解锁后 / 无信号时 / 首次解锁后 |
| 等待时间 | 下拉 | 5~15 秒 |
| 飞行模式持续时间 | 下拉 | 3~9 秒 |
| 无信号重试间隔 | 输入 `xx:xx` | 分:秒 |

## 安装

1. 用 Magisk 安装本模块 zip
2. 重启生效
3. 通过「操作」按钮打开配置页调整参数

## 要求

- 已 root（Magisk，自带 busybox）

## 目录结构

```
├── module.prop        # 模块信息
├── config             # 运行时配置（WebUI 写入）
├── common.sh          # 公共函数（飞行模式开关、信号/飞行模式检测）
├── main.sh            # 主逻辑（三种触发动作）
├── service.sh         # 启动 HTTP 服务 + 主逻辑
├── action.sh          # 「操作」按钮 → 打开 WebUI
└── webroot/
    ├── index.html     # WebUI 前端
    └── cgi-bin/
        └── config.sh  # 配置读写 CGI 后端
```
