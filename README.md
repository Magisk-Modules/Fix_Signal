# 自动修复信号 (fix_signal_auto)

一个 Magisk 模块：开机后自动开关一次飞行模式，修复Blue Fox Aura A1手机root后联通手机重启后 SIM 解锁但无信号的问题。

## 适用场景

- 运营商已退网 2G/3G（如中国联通），手机重启后 SIM 解锁完成但显示无信号
- 需要手动开关飞行模式才能恢复信号的设备（常见于国际版/小众品牌机型）

## 工作原理

```
开机 → 等系统启动完成 → 等 SIM 卡解锁(输入 PIN) → 等 5 秒 → 自动开关一次飞行模式
```

## 安装

1. 用 Magisk 安装本模块 zip
2. 重启生效

## 要求

- 已 root（Magisk）
